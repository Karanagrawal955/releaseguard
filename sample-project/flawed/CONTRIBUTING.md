## Testing

Run `npm test` before opening a PR. Every module under `src/` must have a
matching file under `tests/`.

> Note: Marcus stepped away from the project; pricing changes currently
> require a second reviewer from the cart team.

## Style

Two-space indent, CommonJS modules, no semicolon-free style debates — just
match the file you're editing.
